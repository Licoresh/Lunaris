# Two-minute demonstration guide

1. Open the Moon Explorer and rotate/zoom the globe. Point out automatic NASA model detection and the labeled fallback.
2. Choose Shackleton Rim from the accessible selector, then use **Focus**. Explain that the marker is a published research reference point, not a certified landing ellipse.
3. Select mission dates and choose **Check analysis availability**. LUNARIS refuses to turn a historical average into a date-specific prediction.
4. Open Site Comparison and switch Site B. Explain that every figure is a 1 km neighborhood median with common units and no arbitrary suitability score.
5. Select Malapert Massif to demonstrate partial coverage: historical illumination and Earth visibility are available while terrain remains explicitly unavailable.
6. Show Data Sources and explain the lunar polar transform, GeoTIFF scale factors, checksums and generated compact JSON.

Do not describe the procedural sphere as NASA terrain or historical averages as mission-date predictions.
